==============================================
 TrailFollow - DDO 멀티박스 보조 플러그인
 made by Madmachine
==============================================

Dungeon Helper(DH)에 붙여 쓰는 플러그인입니다.
한 PC에서 여러 캐릭터를 돌릴 때, 서브 캐릭터들이 메인을 따라다니고
버프·힐·공격 같은 반복 동작을 대신해 줍니다. Awesome AF를 대신해 쓰는 용도입니다.

[주요 기능]
- 따라가기: 메인이 걸어간 길(발자취)을 그대로 따라갑니다. 막히면 점프하며 스스로 빠져나옵니다.
  가까이 / 멀리 두 가지 거리를 버튼으로 바꿀 수 있습니다.
- 메인 창: 버튼 하나로 모든 서브를 한꺼번에 조작합니다.
  [따라오기] [가까이/멀리] [- 거리 +] [타게팅] [AFK] [공격] [버프]
- 서브 핫바 창: 서브의 핫바 한 줄이 메인 화면에 아이콘으로 뜹니다. 누르면 그 서브가 사용합니다.
- 자동 힐/버프: 정해 둔 핫바 칸을 정해 둔 간격으로 사용합니다.
  근처에 적이 있을 때만 쓰고, 마을에서는 쉽니다. 체력이 낮은 파티원에게 쓰는 비상 힐도 있습니다.
- 공격: 서브들이 메인과 같은 대상을 잡고 자동 공격을 켭니다. 멈춰 있을 때는 적을 정면으로 봅니다.
- 따라 하기: 메인이 Ctrl을 누른 채 문·레버·상자·NPC·던전 입구를 쓰면 서브들도 같이 씁니다.
  탈것 타기, 리콜, 던전 입장, 퀘스트 대화 선택도 따라 합니다.
- 상자 아이템: 서브 몫으로 나온 상자 아이템을 메인에게 넘깁니다.
- 자동 수락: 파티 초대, 퀘스트 공유, 부활, 비공정 초대, 그레이터 텔레포트

[설치 방법]  (Windows)

■ 1단계: Dungeon Helper 설치 (이미 쓰고 있으면 건너뛰기)
1. https://dungeonhelper.com/ 에서 "Download Here"를 눌러 DungeonHelper.msi 를 받아 설치합니다.
   - 예전 버전(DH 3 이하)이 있으면 먼저 지우고 설치하세요.
2. Dungeon Helper는 "관리자 권한으로 실행"해야 합니다.
   (아이콘 우클릭 → 관리자 권한으로 실행)
3. 게임은 창 모드, 64비트 클라이언트로 실행해야 합니다.
4. 처음에는 Dungeon Helper를 먼저 켜고 그다음 게임을 켭니다.

■ 2단계: TrailFollow 설치
1. 받은 압축 파일을 풀기 "전에" 차단을 해제합니다. (Windows 11 "스마트 앱 컨트롤" 때문)
   - 압축 파일 우클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인
   - 그다음 아무 폴더에나 압축을 풉니다. (예: 다운로드 폴더)
   - 이미 풀었다면 풀어 둔 폴더를 지우고, 차단 해제한 압축 파일로 다시 푸세요.
2. Dungeon Helper를 완전히 끕니다. (작업 표시줄 오른쪽 아래 트레이 아이콘까지 종료)
3. 압축을 푼 폴더에서 build_and_install.bat 을 더블클릭합니다.
   - 처음 한 번은 필요한 도구(.NET 8 SDK)를 자동으로 설치합니다. 몇 분 걸리고,
     "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 "예"를 누르세요.
   - 마지막에 Done! 이 나오면 설치 완료입니다.
4. Dungeon Helper를 켜고 플러그인 목록에서
   - TrailFollow 는 켜기
   - Awesome AF 는 끄기 (둘 다 켜면 서로 충돌합니다)

업데이트할 때는 새 파일을 받아 2단계의 2~3번만 다시 하면 됩니다. 설정은 그대로 남습니다.

※ 설치 중에 뜰 수 있는 경고창 (정상입니다)
- 구글 드라이브에서 받을 때 "바이러스 검사를 할 수 없습니다" 같은 경고가 뜨면
  → "무시하고 다운로드"를 누르세요. (압축 안에 .bat 파일이 있어서 뜹니다)
- build_and_install.bat 을 실행할 때 파란 "Windows의 PC 보호" 창이 뜨면
  → "추가 정보"를 누른 뒤 "실행"을 누르세요. (인터넷에서 받은 실행 파일이라 뜹니다)
- "스마트 앱 컨트롤이 안전하지 않을 수 있는 파일을 차단했습니다" 창이 뜨면
  → 이 창에는 실행 버튼이 없습니다. 위 2단계 1번처럼 압축 파일을 "차단 해제"한 뒤 다시 풀어 주세요.
  (스마트 앱 컨트롤을 끄는 방법은 권하지 않습니다. 한 번 끄면 Windows를 새로 설치하기 전에는 다시 켤 수 없습니다.)

[처음 쓸 때]
1. 게임에서 캐릭터들로 접속하면 서브마다 작은 핫바 창이, 메인에는 메인 창이 뜹니다.
2. 메인 창의 [따라오기]를 누르면 서브들이 지금 조작 중인 캐릭터를 따라옵니다.
3. 핫바 칸 위치는 사람마다 다르니, DH의 TrailFollow 설정에서 꼭 자기 배치에 맞게 바꿔 주세요.
   - 자동 공격 버튼 칸: 기본 핫바 10번 줄 8번 칸 (10.8)
   - [버프] 버튼이 누르는 줄: 기본 핫바 8번 줄 1~10번 칸
   - 리더와 30m 이상 멀어지면 누르는 칸: 기본 3.1 (이동 속도 스킬 등)
   - 비상 힐: 기본 꺼짐, 켜면 8.1 칸 사용
   - 자동 힐/버프 타이머: 서브마다 칸과 간격을 직접 등록합니다
   - 자동 힐/버프와 비상 힐은 서브 핫바 창의 AUTO 버튼을 켜야 동작합니다
4. Ctrl 따라 하기는 메인이 Ctrl을 누른 채로 대상을 클릭(사용)하면 됩니다.

[알아 둘 점]
- 화면과 설정이 모두 한국어입니다.
- 개인이 만들어 쓰는 프로그램이라 모든 상황에서 완벽하게 동작하지는 않습니다.
  물속, 복잡한 지형, 기술로 순간이동한 구간에서는 직접 옮겨 줘야 할 때가 있습니다.
- 자동 따라가기·자동 힐 같은 기능은 게임 운영 정책상 문제가 될 수 있습니다.
  계정 제재 위험은 각자 판단해서 사용해 주세요.
- 문제가 생기면 %AppData%\Dungeon Helper 폴더의 DungeonHelper-Log.txt 를 복사해서 보내 주세요.
  (로그에는 캐릭터 이름이 들어 있으니 아무 데나 올리지는 마세요.)
